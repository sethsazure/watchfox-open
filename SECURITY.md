# Security

Found a vulnerability? Please email **hello@watchfox.run** with the steps to reproduce, and do not open a public issue. We will
answer within a few days and credit you if you wish.

This repository contains no secrets. All credentials (API keys, signing secret, database address, sign-in client secrets, payment and
email tokens) come from environment variables; see `.env.example`. If you ever find a real secret in the history, tell us at once.

What the project already does about the usual problems is described in the "Security" section of the README.
